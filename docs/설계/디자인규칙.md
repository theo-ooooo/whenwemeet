## 1. 원칙

1. **구역으로 짠다.** 화면은 "제목줄 + 내용" 구역을 위에서 아래로 쌓는다. 구역마다 같은 여백, 같은 제목 모양
2. **같은 줄에 맞춘다.** 좌우 여백, 카드 간격, 카드 폭을 화면 전체에서 하나로. 눈으로 세로선이 보여야 한다
3. **강조는 코랄 하나, 한 화면에 적게.** 코랄은 면(FAB, 겹침 조각, 새 소식 점)과 글자(오늘, 비는 시간 값)로만. 큰 코랄 면은 FAB 하나
4. **서비스 모양을 지킨다.** 바탕 `--bg`, 흰 카드 `--tile`, Pretendard, 유리 알약 독 + 코랄 원형 FAB 는 바꾸지 않는다
5. **로고 콘셉트 "겹치는 두 날"** 이 아이콘과 선택 상태의 출처다 (3장, 4장)

### 2-3 홈과 일 상세 (2026-11-10 확정: A + B)
- **홈 = 한 달 달력 + 가로 카드 구역** (시안 A). 머리줄은 심볼(글자 없는 로고) + 팀 이름 20/700 + ⌄
- **날짜를 누르면 일 상세 = 주간 줄 + 그날 요약 + 그날 일정** (시안 B). 지금의 날짜 바텀 시트(DaySheet) 를 대신한다
  - 제목 "11월 10일 (화)", 오른쪽 "월 보기" 알약 → 홈으로
  - 주간 줄: 7칸(높이 70, 모서리 14, 흰 면), 선택일은 `--sel-fill` 면 + 흰 글자, 칸 아래 멤버 점. 다른 날을 누르거나 옆으로 넘기면 그날로
  - 그날 요약: 흰 카드 한 장에 두 줄(비는 시간, 기념일), 줄마다 겹침 아이콘 20 + 라벨 14 + 값 15/700 `--acc-ink`
  - 이날 일정: 제목 "이날 일정 N개" + 오른쪽 "+ 이날 추가"(`--btn` 글자). 왼쪽 48px 시각 열(라벨 11, 시각 16/700), 오른쪽 흰 카드에 3px 멤버 막대 + 제목 + 시각/등록자
- 뒤로가기는 홈으로 (D-58 의 `pushState` 규칙 유지)
- 로고는 글자 없이 심볼만 쓴다 (머리줄, 사이드바). 가로 로고(워드마크)는 로그인, 스토어, 약관에만

D-58 의 "레일 + 2단(달력 | 개요 칸)" 은 이 짜임으로 바뀐다. 개요 칸 내용은 사이드바 아래 묶음과 요약 카드로 옮긴다.

## 4. 메뉴

### 4-1 폰 독
- 유리 알약 안에 **선택된 메뉴만 먹색 칩(`--ink` 면, 높이 44, 모서리 22, 안쪽 왼쪽 10 오른쪽 14) + 흰 아이콘 24 + 이름(14/700, 아이콘과 6)**. 나머지는 아이콘만 (26)
- 아이콘만 있는 항목은 `aria-label` 필수, 칸마다 누르는 영역 최소 44×44(칸 폭 44, 알약 안쪽 좌우 6), 남는 폭은 칸 사이에 고르게
- 칩이 옮겨갈 때 폭과 위치를 200ms 로 (`prefers-reduced-motion` 이면 즉시)
- 칩은 **누른 순간** 옮긴다. 화면은 서버 응답을 기다리지 않고 그 화면의 뼈대(제목 + 스켈레톤, `loading.tsx`)로 바로 바뀐다 (#339, D-213). 사이드바 메뉴도 같다
- 순서 고정 5칸 (#332, D-212): 달력, 빈 시간, 할 일, 기념일, 팀. 새 소식은 머리줄 종. 할 일 칩은 목록 화면(`/todos`)에서 켜지고, 목록 상세는 독을 숨긴다
- 폭 390 이상(`dock` 구간): 알약과 + 가 한 줄(간격 8). 390 미만(360, 폴드 커버 320): 알약이 줄 폭(좌우 16 안)을 다 쓰고 + 는 알약 위 오른쪽에 12 띄워 얹는다. 본문 하단 여백과 알림 토스트도 그만큼(64 + 12) 올린다. 알약 왼쪽 빈 자리는 본문을 누를 수 있다

### 4-2 사이드바
- 줄 높이 46, 모서리 14, 아이콘 24 + 이름 15
- 선택: 먹색 면 + 흰 글자 700 + 코랄 조각. 평소: 면 없음, 글자 `--soft` 500, 아이콘 `--mute`

### 4-3 다크
- 먹색 칩은 다크에서 `--ink`(밝은 글자색) 면 + `--bg` 글자로 뒤집는다. 코랄 조각은 `--pri` 다크값

## 8. 공통 부품 (#378, D-252)
시안: 입력 화면 통일 https://claude.ai/artifact/C4NDZFGeNXqNDDCSj2pcQh , 일 상세 C안과 빈 시간 https://claude.ai/artifact/MXQ5oerWEYvBhs94iK41Xs , 나머지 9개 화면 https://claude.ai/artifact/5xQgifpHExaS4sV1dPGtx2 .
화면을 새로 짜거나 고칠 때 아래 부품을 쓰고 같은 역할의 모양을 따로 만들지 않는다.

### 8-0 공통 규칙
1. **하위 화면 머리줄은 "‹ 제목" 하나**, 오른쪽에는 그 화면의 "⋯" 하나만. "뒤로" 알약, "‹ 달력" 알약은 없앤다
2. **지우기(나가기)는 "⋯" 메뉴 안**, 고르면 확인 창, 일정은 지운 뒤 되돌리기(#375). 화면에 늘 보이는 삭제 버튼, 항목마다 ✕ 를 두지 않는다
3. **설정 칸은 두 가지 줄**: "아이콘 이름 ··· 값 ›" 줄과 토글 줄. "바꾸기" 버튼을 두지 않고 줄을 누르게 한다. 같은 묶음의 줄은 카드 한 장(RowGroup)
4. **안내 문장은 꼭 필요한 곳에 한 줄**. 토글 설명도 한 줄
5. **아래 탭 막대가 내용을 가리지 않게** 본문 아래 여백은 `--dock-clearance`
6. 이름은 맨 위 큰 칸(라벨 없음), 글자 수는 80% 넘을 때만. 4개 이하 짧은 선택은 칸 안 세그먼트, 많으면 줄 → 시트. 저장 버튼은 맨 아래 한 자리(새로 만들면 "추가", 고치면 "저장")
7. 이모지 금지, 아이콘은 `components/icons.tsx` 선 아이콘만(3장)

### 8-1 머리줄 `ScreenHeader` (components/ScreenHeader.tsx)

### 8-7 달력 키보드와 읽기 (#201, D-255)
월 달력, 날짜 피커, 일 상세 주간 줄, 주 보기 날짜 머리가 같은 키를 쓴다(`lib/calendar-keys.ts`).

| 항목 | 값 |
|------|-----|
| 짜임 | `role="grid"`(이름 "2026년 11월") > 요일 머리 `row` + `columnheader`("일요일") > 주마다 `row`(`display: contents`, 모양 그대로) > `gridcell aria-selected` > 칸 버튼 하나 |
| Tab | 격자 안 정지점은 칸 하나(roving tabindex). 방향키로 옮겨 둔 칸 → 선택한 날 → 오늘 → 1일 중 그 달 안의 첫 칸 |
| 키 | ← → 하루, ↑ ↓ 한 주, Home End 그 주 일/토, PageUp PageDown 한 달(없는 날은 말일), Shift+PageUp PageDown 한 해. 달 밖으로 나가면 달을 바꾸고 그 날짜에 포커스. Enter Space 그날 상세, Esc 닫고 그 칸으로. T(오늘) 없음 |
| 포커스만 | 방향키는 포커스만 옮긴다. 주소(`?day=`)와 선택은 Enter 로 열 때만 바뀐다 |
| 읽기 | 칸 "11월 12일 (목), 공휴일, 기념일 …, 일정 2개". 오늘은 `aria-current="date"`(라벨에 "오늘" 없음), 선택은 `aria-selected`. 첫 일정 제목은 읽지 않는다(상세에서) |
| 칩, 막대 | 칸 안 일정 칩과 여러 날 막대는 마우스, 터치 지름길: `tabIndex=-1` + `aria-hidden`. 키보드, 스크린리더는 칸 → 상세 목록 |
| 월 알림 | 화면 밖 `aria-live="polite"` 한 줄이 "2026년 12월"(주 보기는 주 제목)을 읽는다. ‹ ›, 스와이프, 방향키 어느 쪽이든 |
| 포커스 링 | 칸은 안쪽 2px `--ink` 테두리(형제 표시, z 2, `[data-ring-inside]`). 바깥 링은 옆 칸 선, 겹친 칩, 카드 가장자리에 잘린다. 칸 버튼 `scroll-margin-bottom: var(--dock-clearance)` 로 폰 독에 가리지 않는다 |
| 복귀 | 폰 일 상세(월 보기 알약, 뒤로가기, Esc), 넓은 화면 패널(✕, Esc)을 닫으면 그때 날짜 칸으로 포커스. 주 보기는 그 날짜 머리 |
| 주간 줄, 주 머리 | 한 줄: ← → Home End. 일 상세 주간 줄은 주 밖으로 나가거나 PageUp PageDown 이면 그날로 바꾼다. 주 보기 머리는 이 주 안에서만(주는 ‹ ›) |

## 7. 금지
- 한 화면에 코랄 면 둘 이상 (FAB 외)
- 카드마다 다른 폭, 구역마다 다른 좌우 여백
- 아이콘에 겹침 조각 둘 이상, 다른 세트 아이콘 섞기, 이모지
- 문서와 화면 문구의 가운데 점 나열 (A, B 로 풀어 쓴다)
- 새 색 추가. 필요하면 `디자인토큰.md` 를 먼저 고친다
