# 디자인 토큰

- 이슈: #8
- 원본: `brand/` (SVG), 아이콘: `apps/web/public/`

## 생각
"언제볼까" 는 두 사람의 날이 겹치는 자리를 찾는 앱이다. 심볼은 **두 장의 날(둥근 사각형)이 겹치고, 겹친 자리에 점 하나** — 우리가 만나는 그 시간. 하늘과 분홍은 서로 다른 두 사람(기본 멤버 색), 겹친 보라가 브랜드 색이다. 멤버 색이 섞여 브랜드 색이 된다는 규칙은 화면 안에서도 그대로 쓴다.

## 색
| 토큰 | 값 | 용도 |
|------|----|------|
| `--brand` | `#6E4BFF` 보라 | 주요 버튼, 선택된 날짜, 빈 시간 후보, 링크 |
| `--member-1` | `#3FB0FF` 하늘 | 첫 번째 멤버 기본 색 |
| `--member-2` | `#FF5C8A` 분홍 | 두 번째 멤버 기본 색 |
| `--member-3` | `#2ED3A5` 민트 | 세 번째 |
| `--member-4` | `#FFB224` 노랑 | 네 번째 |
| `--member-5` | `#FF7A45` 주황 | 다섯 번째 이후 순환 |
| `--ink` | `#17171C` | 본문 글자 |
| `--ink-2` | `#6B6B76` | 보조 글자, 지난 날짜 |
| `--line` | `#E6E6EB` | 구분선 |
| `--surface` | `#F2F2F5` | 바탕 |
| `--paper` | `#FFFFFF` | 카드, 시트 |
| `--night` | `#15141C` | 다크 모드 바탕, 앱 아이콘 바탕 |
| `--kakao` | `#FEE500` / 글자 `#191919` | 카카오 로그인 버튼만. 변경 금지 |

규칙: 멤버 색은 점과 띠에만 쓰고 글자색으로 쓰지 않는다. 멤버 색만으로 구분하지 않고 이름을 병기한다.

## 서체
| 역할 | 값 |
|------|----|
| 가족 | Pretendard Variable 하나 (`https://cdn.jsdelivr.net/gh/orioncactus/pretendard/dist/web/variable/pretendardvariable-dynamic-subset.min.css`) |
| 큰 제목 (달력의 월 숫자) | 800 / 40px / 자간 -0.04em / 행간 1.0 |
| 제목 | 700 / 20px / -0.02em / 1.3 |
| 본문 | 500 / 15px / -0.01em / 1.5 |
| 보조 | 500 / 13px / 0 / 1.4, `--ink-2` |
| 날짜 숫자 (그리드) | 600 / 15px, 오늘은 `--brand` 원 안에 흰 글자 |

## 모양과 간격
- 모서리: 작은 요소 8px, 카드와 시트 16px, 앱 아이콘 112/512
- 간격 단위 4px. 화면 좌우 여백 20px
- 그림자 없음. 층은 배경색 차이(`--surface` 위 `--paper`) 로만
- 모션: 시트 열림/닫힘 200ms, 날짜 선택 120ms. `prefers-reduced-motion` 이면 즉시

## 로고 사용
| 파일 | 쓰는 곳 |
|------|--------|
| `brand/logo-symbol.svg` | 앱 안 상단, 로딩, 파비콘 원본 |
| `brand/logo-horizontal.svg` / `-dark.svg` | 로그인 화면, 랜딩, 공유 이미지 |
| `brand/logo-stacked.svg` / `-dark.svg` | 스플래시, 정사각형 자리 |
| `brand/app-icon.svg` → `public/icon-512.png` 등 | PWA manifest, 홈 화면 |
- 최소 크기: 심볼 16px, 가로 로고 높이 24px
- 여백: 심볼 한 변의 1/4 이상 비움
- 색 바꾸기, 기울이기, 그림자 금지. 단색이 필요하면 `--ink` 또는 흰색 한 가지로
