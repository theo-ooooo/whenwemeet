## 생각
연회색 바탕 위 흰 타일(벤토), 큰 월 숫자, 반투명 떠 있는 탭과 알약 버튼. 서비스의 핵심인 "오늘 모두 비는 시간" 을 연한 코랄 타일 + 코랄 시간 숫자로 첫 화면 맨 위에 둔다. #24 의 먹색 면은 #46 에서 소프트 코랄로 바꿨다 (검정 면이 무겁다는 리뷰). 검정 면은 쓰지 않는다: 먹은 부드러운 차콜, 강조 면은 옅은 코랄, 강한 점(+ 버튼, 주 버튼)만 코랄. 심볼은 두 장의 날(레드, 블루)이 겹친 자리에 보라.

### 강조 방식 (면 줄이기)
- 옅은 코랄 면(`--hl-tile`, `--today-bg`) 을 큰 타일과 버튼 바탕에 쓰지 않는다. 강조는 **글자색 `--acc-ink` 와 점, 2~3px 세로 막대**로
- "오늘 둘 다 비는 시간", "처음 만난 날" 은 타일 두 장 대신 카드 하나의 정보 줄 두 개 (선 아이콘 + 라벨 + `--acc-ink` 값)
- 선택 날짜는 칸 전체 채움 대신 숫자 뒤 26px 원 `--sel-fill` + 흰 글자. 오늘(선택 안 됨)은 숫자만 `--today-ink`
- 일정 표시는 멤버 색 점(5px) 과 행 왼쪽 3px 막대. 여러 날 일정만 칸을 잇는 4px 막대
- "오늘" 배지는 면 없이 12/700 `--today-ink` 글자
- 코랄로 채우는 것은 FAB, 주 버튼, 선택 날짜 원 세 가지

### 색 A (확정): 역할 분리
문제: 빨강/코랄 하나가 (1) 주말과 공휴일, (2) 버튼, 선택 날짜, 비는 시간 같은 강조, (3) 멤버 색(첫 멤버 = 빨강) 세 가지 뜻을 같이 져서 점과 막대가 무엇인지 알 수 없었다. A 는 코랄을 **강조 전용**으로 두고, 주말은 채도를 낮춘 장미빛 빨강, 멤버 색에서는 빨강과 주황을 뺀다.

**기존 멤버 색 옮기기 (데이터 이전 없음)**
- 서버는 `MEMBER_COLORS` 8개 hex(`#F26D6D` 등) 중 하나를 `Membership.color` 에 저장하고, 화면은 이미 그 hex 의 **순번**만 보고 CSS 변수로 바꿔 그린다 (`apps/web/src/lib/colors.ts memberColor`). 서버 hex 는 사실상 키다
- 그래서 **화면 매핑만 바꾼다**: `DISPLAY` 를 `--m1`~`--m7` 7개로 바꾸면 순번 0(`#F26D6D`, 지금 빨강으로 보이는 첫 멤버)은 블루, 1(`#F2994A`, 주황)은 머스터드로 보인다. 기존 팀의 빨강, 주황 멤버가 배포 즉시 사라지고 DB 는 건드리지 않는다
- 순번 7(`#F279B5`)은 8번째 키라 7색으로 나누면 블루와 겹친다. API `pickLeastUsedColor` 의 배정 후보를 앞 7개(`MEMBER_COLORS.slice(0, 7)`)로 줄여 새 배정에서는 나오지 않게 하고, 이미 그 값을 가진 멤버는 화면에서 순번 7 → `--m7`(슬레이트)로 따로 매핑한다 (`i < 7 ? i : 6`)
- 팀 설정 팔레트(`PICKABLE_COLORS`)는 앞 7개
- 서버 hex 를 새 색 값으로 바꾸는 DB 이전은 하지 않는다. 키와 표시를 분리한 지금 구조라 의미가 없고, API 계약(`api.md` 2.2)과 앱 셸에 영향만 준다. 나중에 키 이름을 바꾸고 싶으면 `UPDATE Membership SET color = CASE ...` 한 번과 API 상수 교체를 같은 배포에 묶는다
