# 디자인 토큰 (2026)

- 이슈: #8 (최초), #24 (2026 교체), #46 (소프트 코랄 톤, 달력에서 바로 추가)
- 톤 기준: `docs/설계/img/톤-소프트코랄.png` 가운데 A안 (#46 사용자 확정)
- 기준 목업: `docs/설계/img/디자인-2026.html` (모바일 라이트, 다크, 일정 상세 시트), `디자인-2026-PC.html` (PC 라이트/다크). 값은 목업 CSS 를 그대로 옮긴다
- 구현: `apps/web/src/app/globals.css` (`:root` 변수 + Tailwind `@theme inline`)

## 생각
연회색 바탕 위 흰 타일(벤토), 큰 월 숫자, 반투명 떠 있는 탭과 알약 버튼. 서비스의 핵심인 "오늘 모두 비는 시간" 을 연한 코랄 타일 + 코랄 시간 숫자로 첫 화면 맨 위에 둔다. #24 의 먹색 면은 #46 에서 소프트 코랄로 바꿨다 (검정 면이 무겁다는 리뷰). 검정 면은 쓰지 않는다: 먹은 부드러운 차콜, 강조 면은 옅은 코랄, 강한 점(+ 버튼, 주 버튼)만 코랄. 심볼은 두 장의 날(레드, 블루)이 겹친 자리에 보라.

## 테마
- 기본은 `prefers-color-scheme`. 내 정보 > 화면 테마에서 시스템/라이트/다크 수동 전환
- 수동 값은 `localStorage.wwm_theme` 에 저장, `<html data-theme="light|dark">` 로 적용. 첫 페인트 깜빡임을 막으려고 `<head>` 인라인 스크립트(`lib/theme.ts THEME_SCRIPT`)가 렌더 전에 단다

## 모양과 간격
| 요소 | 모서리 | Tailwind |
|------|--------|----------|
| PC 칩 | 7px | `rounded-xs` |
| 날짜 칸, 입력, 메뉴 | 14px | `rounded-sm` |
| 타일 (비는 시간, D-day) | 22px | `rounded-lg` |
| 달력/목록 타일 | 26px (PC 달력 24px) | `rounded-xl` |
| 바텀 시트 위 모서리 | 30px | `rounded-2xl` |
| 버튼, 탭, 상단 알약 | 999px | `rounded-full` |

- 모바일 화면 좌우 16px, 타일 사이 8px. 떠 있는 탭이 있는 화면은 본문 하단 여백 `calc(64px + 22px + 32px + env(safe-area-inset-bottom))` (탭 높이 + 탭 아래 띄움 + 여유) 로 마지막 항목이 탭에 가리지 않게. 주 버튼 높이 52px, 카카오 58px, 떠 있는 탭 64px + 코랄 원형 + 64px
- PC(≥1024px): 사이드바 232px / 가운데 / 우측 패널 320px, 바깥 여백 26px 22px
- 그림자: 떠 있는 탭, + 버튼(`--fab-shadow`, 라이트는 코랄 32%), PC 빠른 추가 팝오버(`--pop-shadow`)만. 나머지 층은 바탕색 차이로
- 반투명: 상단 알약 `rgba(255,255,255,.7)` blur 12, 탭 `.78` blur 16 (다크 `rgba(32,32,36,.82)`)
- 모션: 시트 200ms, 날짜 선택 120ms. `prefers-reduced-motion` 이면 즉시

## 달력에서 바로 추가 (#46)
- 구현: `apps/web/src/components/QuickAdd.tsx` (`QuickAddSheet` 모바일, `QuickAddPopover` PC). 저장은 `useCreateEvent`
- 모바일: 날짜 1탭 = 선택, 선택된 날짜 재탭 = 바텀 시트 (위 모서리 30px). 일정 없는 날 목록에 "이 날 일정 추가" 알약 버튼
- PC: 날짜 칸 빈 곳 클릭 = 그 칸 오른쪽(자리 없으면 왼쪽) 340px 팝오버, 모서리 26px, `--line` 테두리 + `--pop-shadow`. 일정 칩 클릭은 우측 상세(현행)
- 필드: 제목(52px 입력), 종일 토글, 시작/종료 시각(같은 날, 시작을 옮기면 길이 유지). 버튼: "자세히"(보조 알약) + "저장"(주 알약, 52px)
- "자세히" 는 새 일정 폼으로 `start`, `end`, `title`, `allDay=1` 쿼리를 넘긴다
- 접근성: `role=dialog` + 제목 연결, 열면 제목 입력에 포커스, Tab 은 창 안에서 돈다, Esc 와 바깥 클릭으로 닫고 원래 날짜 칸으로 포커스를 돌린다. 날짜 칸 라벨에 "한 번 더 누르면 일정 추가"(모바일 선택 칸), "눌러서 일정 추가"(PC)

## 밀도 조정 (제안, 미확정, #99)

- 상태: **제안**. 위 표가 현행값이고, 사용자 확정 전에는 코드에 반영하지 않는다

- 참고 밀도: 본문 14/20 400, 메뉴 행 14/700 높이 약 40px 모서리 10px, 버튼 13.5/700 모서리 14px, 섹션 제목 약 20px, 메타 11~12px
- 시안: `docs/설계/img/밀도-시안.html` (`?f=phone-cal|phone-sheet|wide-day|pc-cal`, `&dark`), 렌더 `density-*.png`, 전후 비교 `density-compare-phone.png`, `density-compare-wide.png`

### 강조 방식 (면 줄이기)
- 옅은 코랄 면(`--hl-tile`, `--today-bg`) 을 큰 타일과 버튼 바탕에 쓰지 않는다. 강조는 **글자색 `--hl-time` 과 점, 2~3px 세로 막대**로
- "오늘 둘 다 비는 시간", "처음 만난 날" 은 타일 두 장 대신 카드 하나의 정보 줄 두 개 (선 아이콘 + 라벨 + 코랄 값)
- 선택 날짜는 칸 전체 채움 대신 숫자 뒤 26px 원 `--pri` + 흰 글자. 오늘(선택 안 됨)은 숫자만 `--today-ink`
- 일정 표시는 멤버 색 점(5px) 과 행 왼쪽 3px 막대. 여러 날 일정만 칸을 잇는 4px 막대
- "오늘" 배지는 면 없이 12/700 `--today-ink` 글자
- 코랄로 채우는 것은 FAB, 주 버튼, 선택 날짜 원 세 가지
