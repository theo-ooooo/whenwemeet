# 서비스 워커 (#203, D-256)

브라우저(PWA 포함) 사용자에게 오프라인 안내 화면을 보이고 해시 붙은 정적 자산만 캐시한다. 앱 셸 웹뷰에서는 등록하지 않는다(셸이 #270 오프라인 화면을 그린다).

## 1. 구성
| 파일 | 역할 |
|------|------|
| `apps/web/public/sw.js` | install(/offline + 그 화면의 `/_next/static` 파일 + 아이콘 사전 캐시, `skipWaiting`), activate(옛 `wwm-static-*` 삭제, `clients.claim`), fetch |
| `apps/web/public/sw-rules.js` | 요청 분류, 응답 캐시 허용 판정 (순수 함수, `importScripts`). 테스트 `src/lib/__tests__/sw-rules.test.ts` |
| `apps/web/src/components/ServiceWorkerRegister.tsx` | 루트 레이아웃에서 등록. 앱 셸 UA(`WhenwemeetApp/`)면 등록 해제 + 캐시 삭제 |
| `apps/web/src/app/offline/page.tsx` | 정적 안내 화면 (쿠키, API 안 씀) |
| `apps/web/next.config.ts` | `/sw.js`, `/sw-rules.js` 에 `Cache-Control: no-cache, no-store, must-revalidate`. 등록 주소 `?v=` 값 `NEXT_PUBLIC_SW_VERSION` |

## 2. 규칙 (위에서부터 처음 맞는 것)
1. GET 아님: 관여 안 함. 단 `POST /auth/logout`(로그아웃, 탈퇴)은 응답은 그대로 두고 캐시를 비운 뒤 /offline 을 다시 넣는다
2. 다른 출처(jsDelivr 글꼴, 카카오, API 도메인): 관여 안 함
3. `/api`, `/auth`, `/.well-known`, `/og*`, `/join*`, `opengraph-image`, `twitter-image`, `/sw.js`, `/sw-rules.js`: 관여 안 함 (문서 이동이어도)
4. RSC(`?_rsc=`, `RSC`, `Next-Router-Prefetch`, `Next-Action` 헤더): 관여 안 함. 오프라인이면 Next 가 문서 이동으로 바꿔 5번의 /offline 이 뜬다 (실측)
5. `/_next/static/*`, 아이콘: cache-first
6. 문서 이동: 네트워크만, 실패하면 캐시의 /offline 을 원래 주소에 그대로 보인다 ([다시 시도] = 새로 고침, `online` 이벤트면 자동)
7. 그 밖: 관여 안 함

캐시에 넣기 직전 응답도 다시 본다: 200, 같은 출처, `basic`, `Set-Cookie` 없음, `no-store`/`private` 없음, HTML 은 `/offline` 만, RSC(`text/x-component`)와 JSON 은 거부.

## 3. 배포와 갱신
- 등록 주소가 `/sw.js?v=<커밋 SHA 12자>`(Vercel) 라 배포마다 새 워커가 설치되고 캐시 이름 `wwm-static-<v>` 가 바뀌어 옛 캐시가 지워진다. 로컬 빌드는 `<버전>-<빌드 시각>`
- 문서를 캐시하지 않으므로 옛 청크와 새 청크가 섞이지 않는다

## 4. 확인 (Chrome)
DevTools > Application > Service workers 에 `/sw.js?v=...` activated. Cache Storage `wwm-static-*` 안에 `/offline` 말고 HTML, `?_rsc=`, `/api` 항목이 없어야 한다. Network 오프라인에서 화면 이동하면 안내 화면.

## 5. 끄기 (자기 해제)
문제가 생기면 `apps/web/public/sw.js` 전체를 아래로 바꿔 배포한다(주소는 그대로 둔다). 다음 방문 때 새 워커가 설치되며 캐시를 모두 지우고 스스로 해제한 뒤 열린 탭을 새로 고친다. 등록 컴포넌트는 그대로 두면 다시 등록하므로 같은 PR 에서 `layout.tsx` 의 `<ServiceWorkerRegister />` 도 뺀다.

```js
self.addEventListener("install", () => self.skipWaiting());
self.addEventListener("activate", (event) => {
  event.waitUntil(
    (async () => {
      const names = await caches.keys();
      await Promise.all(names.filter((n) => n.startsWith("wwm-static-")).map((n) => caches.delete(n)));
      await self.registration.unregister();
      const tabs = await self.clients.matchAll({ type: "window" });
      tabs.forEach((c) => c.navigate(c.url));
    })()
  );
});
```

- 자기 해제 `sw.js` 는 최소 몇 주 둔다(오래 방문하지 않은 브라우저도 다음 방문 때 받는다). `sw.js` 자체가 `no-store` 라 배포 직후부터 적용된다
