# AI 입력 기획 (한 줄로 일정 추가, 카톡 대화 붙여넣기, #450)

- 이슈: #450
- 방향: AI 채팅 화면을 따로 두지 않고 AI 를 입력에 숨긴다. AI 는 글을 해석해 폼을 채우기만 하고, 저장은 사용자가 화면에서 확인한 뒤에 한다 (2026-11-16 사용자 결정)
- 1차 범위: 한 줄로 일정 추가 + 카톡 대화 붙여넣기 (같은 해석기). 빈 시간 찾기를 말로 묻기는 다음 버전

## 1. 목표와 대상
- 일정을 넣는 사람이 날짜, 시각, 참여자를 하나씩 고르는 대신 평소 말하듯 한 줄로 넣는다
- 단톡방에서 이미 정한 약속을 앱에 다시 옮겨 적지 않는다. 서비스 문구 "카톡으로 캡처 주고받기 그만" 과 같은 방향
- 순간: 대화하다 약속이 정해졌을 때, 일정 추가 버튼을 눌렀을 때

## 2. 핵심 흐름
1. 팀 사용자로서, "다음 주 금요일 저녁 7시 강남 회식, 하늘이랑" 이라고 치면 제목, 날짜, 시각, 장소, 참여자가 채워진 일정 폼을 보고 확인만 눌러 저장하고 싶다
2. 단톡방 사용자로서, 약속을 정한 대화를 복사해 붙이면 일정 후보 여러 개를 보고 골라서 넣고 싶다
3. 사용자로서, AI 가 잘못 알아들었거나 알아듣지 못하면 보통 폼으로 바로 고쳐 넣고 싶다 (막히지 않게)

## 3. MVP 기능 목록
| 기능 | 필수/선택 | 비고 |
|------|----------|------|
| 일정 추가 화면 맨 위 한 줄 입력칸 "말로 추가" (예: 다음 주 금요일 7시 강남 회식) | 필수 | 해석이 끝나면 아래 폼이 채워지고 바뀐 칸이 잠깐 강조된다. 저장은 기존 [저장] |
| 해석 항목: 제목, 날짜, 시작, 끝(없으면 1시간), 종일, 장소 글자, 참여자 이름 | 필수 | 날짜는 오늘(KST) 기준 상대 표현 해석. 참여자는 그 팀 멤버 이름과 맞춰 고른다(못 맞추면 비움) |
| 반복("매주 화요일"), 알림, 색은 해석하지 않음 | 필수 | 폼에서 직접. 잘못 해석하면 피해가 큰 항목이라 1차는 뺀다 |
| 카톡 대화 붙여넣기: 일정 추가 화면 "대화에서 찾기" → 붙여넣기 칸 → 일정 후보 목록(최대 5개) → 하나 고르면 같은 폼이 채워짐 | 필수 | 여러 개를 한 번에 저장하지 않는다(하나씩 확인). 후보가 없으면 "약속을 찾지 못했어요" |
| 실패, 모호함: "잘 모르겠어요. 아래에서 직접 골라 주세요" 와 함께 알아들은 칸만 채움 | 필수 | 서버 오류, 시간 초과(8초)도 같은 문구로 폼은 그대로 |
| 사용 한도: 1인 하루 20회(한 줄, 붙여넣기 합산), 넘으면 그날은 입력칸에 안내만 | 필수 | 서버가 센다. 일반 입력은 늘 된다 |
| 입력 길이: 한 줄 200자, 붙여넣기 4,000자 (넘치면 앞부분만 쓰고 안내) | 필수 | 비용과 응답 시간 상한 |
| 처음 쓸 때 한 번 안내: "입력한 글은 일정을 채우려고 OpenAI 로 보내져 해석돼요. 저장하지 않아요" | 필수 | 개인정보처리방침에 처리 위탁, 국외 이전 항목 추가 |
| 앱(웹뷰)에서도 그대로 | 필수 | 웹 화면 기능이라 앱 업데이트 불필요 |

## 4. MVP 제외
- 채팅 화면, 대화 이어가기 (입력을 돕는 것이 목적)
- 빈 시간 찾기를 말로 묻기 (2차. 같은 해석기에 조건 해석만 더한다)
- 여러 일정 한 번에 저장 (잘못 들어간 일정을 지우는 비용이 크다)
- 반복, 알림, 색 해석 (1차는 틀려도 금방 보이는 항목만)
- 음성 입력, 사진(캡처 이미지) 인식
- 일정 수정을 말로 하기 ("회식 8시로 미뤄줘")

## 5. 제약
- 모델: OpenAI `gpt-4o-mini` (Luna 와 같은 모델). 사용자 OpenAI 계정의 선불 잔액으로 쓴다. 키는 운영 서버 환경 변수에만 두고 저장소, 문서, 화면에 남기지 않는다. 키 등록과 OpenAI 쪽 월 사용 한도 설정은 계정 주인이 한다
- 비용(어림): 한 줄 해석 1회 입력 약 1,000토큰 + 출력 약 200토큰, 붙여넣기 1회 입력 약 3,000토큰. gpt-4o-mini 단가(입력 100만 토큰당 약 $0.15, 출력 약 $0.60) 기준 1회 1원 안팎. 한 달 1,000회여도 1,000원 남짓. 단가는 설계 때 OpenAI 가격표로 다시 확인
- 서버만 OpenAI 를 부른다(웹에서 직접 부르지 않음). 키가 없거나 잔액이 떨어지면 입력칸을 숨기지 않고 "지금은 말로 추가를 쓸 수 없어요" 안내 후 보통 폼
- 개인정보: 입력 글, 붙여넣은 대화, 해석 결과를 서버에 저장하지 않는다(로그에도 본문을 남기지 않고 길이, 성공 여부, 걸린 시간만). OpenAI 로는 입력 글, 오늘 날짜, 그 팀 멤버의 닉네임만 보낸다(이메일, 일정 목록은 보내지 않음). 붙여넣은 대화에는 다른 사람 메시지가 들어 있으므로 안내 문구에 밝힌다. OpenAI API 는 기본적으로 학습에 쓰지 않는다는 정책을 처리방침에 적는다
- 운영: 비용 0원 시작 원칙의 예외. 상한은 OpenAI 계정 잔액(선불)과 1인 하루 20회로 둔다

## 6. 성공 기준
- 출시 4주 동안 새 일정 중 AI 입력으로 시작한 비율 15% 이상
- AI 로 채운 폼을 날짜, 시각을 고치지 않고 저장한 비율 70% 이상 (해석 정확도)
- 해석 응답 중간값 3초 이하, 실패(오류, 시간 초과) 5% 이하
