# 언제볼까 MVP 기획

- 이슈: #1
- 상태: 승인 대기 (GATE 1)
- 작성: 2026-11-09

## 1. 목표와 대상

**누가**: 일정을 맞춰야 하는 2~10명의 작은 모임 — 연인, 가족, 친구 모임, 소규모 스터디. 그리고 그 사람이 혼자 쓰는 개인 달력.

**어떤 순간에**: 카톡으로 "언제 볼까?" 를 보내고 서로 캡처한 달력을 주고받는 순간. 이 앱은 그 대화를 **달력 하나를 같이 보는 것** 으로 바꾼다.

**왜 기존 앱이 아닌가**: 구글/네이버 캘린더 공유는 설정이 복잡하고 상대도 같은 서비스를 써야 한다. 카카오 로그인 한 번, 링크 한 번으로 끝나는 가벼움이 핵심이다.

## 2. 핵심 흐름

| # | 유저 스토리 | 완료 기준 |
|---|------------|-----------|
| F1 | 처음 온 사용자로서, 카카오로 로그인하고 팀을 만들어 초대 링크를 카톡으로 보내고 싶다 | 로그인 → 팀 이름 입력 → 링크 공유까지 3탭 |
| F2 | 팀원으로서, 내 일정을 넣고 상대 일정을 같은 달력에서 색으로 구분해 보고 싶다 | 날짜 탭 → 제목 입력 → 저장. 상대가 앱을 열면 보인다 |
| F3 | 약속을 잡으려는 사람으로서, "이번 주에 다 되는 시간" 을 바로 보고 그 자리에 일정을 만들고 싶다 | 빈 시간 찾기 → 후보 선택 → 일정 생성 |

보조: 기념일을 등록하면 달력 상단에 D+N 이 보인다.

## 3. MVP 기능

| 기능 | 필수/선택 | 비고 |
|------|----------|------|
| 카카오 로그인 | 필수 | 수집: 카카오 ID, 닉네임, 프로필 사진. 이메일 수집 안 함 |
| 팀 만들기 (`personal` / `team`) | 필수 | 가입 직후 `personal` 팀 자동 생성. `team` 은 이름 입력 |
| 초대 링크 + 6자리 코드 | 필수 | 같은 코드. 링크 열면 로그인 후 자동 합류. 코드는 재발급 가능 |
| 팀 전환 | 필수 | 상단에서 내 팀 목록 전환. 여러 팀 소속 가능 |
| 월 달력 + 일 목록 | 필수 | 월 그리드에 멤버 색 점, 날짜 선택 시 하단에 그날 일정 |
| 일정 CRUD | 필수 | 제목, 시작/종료, 종일, 메모, 등록자. 팀원 누구나 수정/삭제 가능 |
| 기념일 D-day | 필수 | 팀당 여러 개. 날짜 + 이름. D-day, D+N 표시. **자동 표시(제안, #105)**: 종류(함께한 날 세기 / 매년 반복 / 그날만)에 따라 100일 단위(1000일까지, 이후 1000일 단위), N주년, 매년 같은 날을 달력 칸, 날짜 상세, 다가오는 일정에 표시. 시작일 = 1일. 상세는 `기념일-자동표시.md` |
| 빈 시간 찾기 | 필수 | 기간(이번 주/다음 주/직접) + 최소 길이 선택 → 전원 비는 구간 목록 → 탭하면 일정 생성 폼 |
| 새 소식 | 필수 | 마지막 방문 이후 다른 멤버가 추가/수정/삭제한 일정 목록 + 배지 |
| 멤버 색/닉네임 변경 | 선택 | 팀별로 내 색과 표시 이름 |
| 팀 나가기 / 삭제 | 필수 | 아래 규칙 참조 |
| 회원 탈퇴 | 필수 | 법적 필수. 아래 규칙 참조 |

### 빈 시간 찾기 규칙
- "바쁨" 판정에는 **각 멤버가 속한 모든 팀(개인 팀 포함)의 일정** 을 쓴다. 그래야 실제로 비는 시간이 나온다.
- 다른 팀의 일정 내용은 절대 노출하지 않는다. 결과는 "비는 구간" 만 보여준다.
- 탐색 시간대 기본 09:00~23:00, 최소 길이 기본 2시간. 변경 가능.

### 팀 나가기 / 삭제 / 탈퇴 규칙
- 팀을 나가면 그 팀의 일정은 그대로 남는다. 내가 만든 일정도 남는다 (팀의 자산).
- 마지막 멤버가 나가면 팀과 일정을 삭제한다 (확인 1회).
- 회원 탈퇴 시: 개인 팀과 그 일정 삭제, 다른 팀의 내 일정은 남되 등록자는 "탈퇴한 멤버" 로 표시. 카카오 연결 끊기(unlink) 호출.

## 5. 제약

- **개인정보**: 수집 최소화(카카오 ID, 닉네임, 프로필 사진). 개인정보처리방침과 이용약관 페이지 필수. 탈퇴 시 즉시 삭제.
- **연령**: 카카오 로그인 정책상 만 14세 이상. 약관에 명시.
- **카카오**: Redirect URI, 사이트 도메인 등록은 사용자가 개발자센터에서 직접. 동의항목은 닉네임, 프로필 사진만.
- **비용**: 무료 티어로 시작 (Vercel, Fly/Railway, MySQL 호스팅). 유료 전환은 사용자 확인 후.
- **시간대**: 서버는 UTC 저장, 화면은 KST 고정 (해외 사용자는 범위 밖).

## 6. 성공 기준

| 지표 | 목표 |
|------|------|
| 초대 링크를 받은 사람의 48시간 내 가입율 | 50% 이상 |
