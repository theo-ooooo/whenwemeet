## 1. 목표와 대상

**누가**: 3명 이상인 팀(가족, 친구 모임). 2인 팀도 쓸 수 있지만 주 대상은 아니다.

**어떤 순간에**: 빈 시간 찾기에서 다 같이 비는 시간이 여럿 나왔을 때. 달력에 일정이 없다고 다 되는 시간은 아니라서(이동, 컨디션, 달력에 안 넣은 약속) 결국 카톡으로 "토요일 저녁? 일요일 점심?" 을 다시 묻는다.

**왜 이 앱에서**: 빈 시간 결과에서 후보를 바로 고르고, 정한 후보가 그대로 일정이 된다. 카톡 "언제 돼?" 왕복을 앱 안 한 번으로 끝낸다 (MVP F3 흐름의 연장).

## 2. 핵심 흐름

| # | 유저 스토리 | 완료 기준 |
|---|------------|-----------|
| V1 | 팀원으로서, 빈 시간 결과에서 후보 2~5개를 골라 팀에 묻고 싶다 | 빈 시간 화면 "투표로 정하기" → 결과 줄 체크 → "후보 N개로 투표 만들기" → 제목, 마감, 대상 → 투표 화면 |
| V2 | 팀원으로서, 되는 시간을 골라 답하고 언제든 바꾸고 싶다 | 후보마다 "가능" 을 켜고 끈다. 누가 가능한지 이름이 보인다 |
| V3 | 팀원으로서, 답이 모이면 한 번에 일정으로 만들고 싶다 | "이 시간으로 정하기" → 그 시각, 그 대상으로 일정이 생기고 투표는 끝난다 |
| V4 | 연 사람으로서, 마감이 지나면 정하라는 알림을 받고 싶다 | 마감 시각에 연 사람에게 알림 1건. 자동으로 정하지는 않는다 |
| V5 | 앱을 연 사람으로서, 진행 중인 투표를 홈에서 보고 싶다 | 폰 홈 "정하는 중" 구역(있을 때만), 넓은 화면 사이드바 한 줄 |

## 3. 기능 목록

| 기능 | 내용 |
|------|------|
| 만들기 | 빈 시간 결과에서 고른 구간마다 최소 길이 후보(구간 안에서 시작 시각 조절). 직접 추가(날짜와 시각, 또는 종일). 제목 1~50자(정하면 일정 제목), 마감 없음 / 내일 / 직접, 대상 기본 "모두"(일정 참여자 시트 재사용) |
| 답하기 | 후보마다 "가능" 하나(3단 답 없음). 익명 아님. 대상만 답한다. 마감이 지나면 받지 않는다 |
| 정하기 | 팀원 누구나. 연 사람이 아니면 확인 창 한 번. 정하기 직전 그 시간에 바빠진 사람이 생겼으면 알려 주고 그대로 정한다 |
| 취소 | 팀원 누구나, 진행 중만. 기록 없이 지운다 |
| 지난 후보 | 시작이 지난 후보는 고를 수도 정할 수도 없다. 모두 지나면 "지난 투표" 로 뒤에 흐리게 |
| 새 소식 | "민지님이 '저녁 약속' 투표를 열었어요", "'저녁 약속' 시간을 정했어요" + 정한 시간. 표는 기록하지 않는다 |
| 알림 | 열림(대상에게), 마감(연 사람에게), 정함(대상에게). 내 정보 > 알림 "약속 투표"(기본 켬) |

**제외**: 마감 때 자동으로 정하기(동률, 0표 처리), "애매해요" 같은 3단 답, 익명 투표, 후보 댓글, 개인 팀(혼자라 의미 없음), 반복 일정 투표(정한 뒤 일정 수정에서 반복을 켤 수 있다), 투표 목록 화면(입구 카드와 새 소식으로 충분).

## 4. 정한 것 (이슈 "정할 것" 추천안)

| # | 질문 | 결정 |
|---|------|------|
| Q1 | 방식 | 빈 시간 후보 투표 + 직접 추가 허용 |
| Q2 | 정하기, 취소 권한 | 팀원 누구나 (D-18 역할 없음). 화면에서 연 사람이 아니면 확인 창 |
| Q3 | 마감 때 자동 확정 | 하지 않는다. 마감 알림으로 사람이 정한다 |
| Q4 | 정할 때 새 소식 두 줄 | "정했어요" 한 줄만. 그 확정으로 생긴 "일정을 추가했어요" 는 숨긴다. 알림도 투표 문구 1건 |
| Q5 | 진행 중 투표 구역이 비었을 때 | 구역을 그리지 않는다 (상시 기능이 아니라서) |
| Q6 | 3단 답 | 처음엔 "가능" 하나 |
| Q7 | 후보 수 상한 | 5개 |

## 5. 지표

- 3명 이상 팀 중 투표를 연 팀 비율, 투표 → 정하기 전환율
- 4주 동안 전환율 30% 미만이면 기능을 줄이거나 접는다
