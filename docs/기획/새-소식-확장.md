# 새 소식 확장 기획 (기념일 변경, 멤버 합류와 나가기)

- 이슈: #191 (로드맵 #205 P2)
- 상태: 승인 (2026-11-11, 이슈의 "정할 것" Q1 ~ Q4 추천안 그대로 확정)
- 선행 관계: #190(참석 여부), #189(약속 투표)는 이 기능의 팀 활동 기록에 종류만 더한다

## 1. 목표와 대상

**누가**: 커플, 가족, 모임 팀의 모든 멤버.

**어떤 순간에**: 새 소식을 열어 "팀에 무슨 일이 있었지?" 를 확인하는 순간. 지금은 일정 추가, 수정, 삭제만 보인다. 상대가 "처음 만난 날" 날짜를 고쳐도, 새 멤버가 들어오거나 누가 나가도, 팀 이름이 바뀌어도 조용히 바뀐다. 합류는 푸시로만 알려 푸시를 놓치거나 웹으로 쓰면 모른다.

## 2. 핵심 흐름

| # | 유저 스토리 | 완료 기준 |
|---|------------|-----------|
| N1 | 멤버로서, 다른 멤버가 기념일을 추가, 수정, 삭제하면 새 소식에서 알고 싶다 | "하늘님이 기념일 '처음 만난 날'의 날짜를 바꿨어요" 한 줄, 누르면 기념일 화면 |
| N2 | 멤버로서, 누가 팀에 들어오고 나갔는지 새 소식에서 보고 싶다 | 합류, 나가기, 탈퇴가 한 줄씩. 나간 사람도 그때 이름으로 보인다 |
| N3 | 멤버로서, 팀 이름이 바뀐 이유를 알고 싶다 | "팀 이름을 '우리집'에서 '우리 가족'으로 바꿨어요" |

## 3. 규칙

| 일 | 남기는 때 | 문구 ("{이름}님이" 뒤) | 누르면 |
|----|----------|------------------------|-------|
| 기념일 추가 | 추가 성공 | 기념일 '처음 만난 날'을 추가했어요 | 기념일 화면 |
| 기념일 수정 | 이름, 날짜, 종류가 실제로 바뀐 경우만 (같은 값, 알림 시점만 바꿈은 남기지 않음) | 바뀐 것 하나: '…'의 날짜를 바꿨어요 / 종류를 바꿨어요 / '이전'의 이름을 '새 이름'으로 바꿨어요. 여럿: '…'을 수정했어요 | 기념일 화면 |
| 기념일 삭제 | 삭제 | 기념일 '처음 만난 날'을 삭제했어요 | 없음 |
| 멤버 합류 | 새로 멤버가 된 경우만 (같은 링크를 다시 눌러도 한 번) | 팀에 들어왔어요 | 팀 설정 |
| 멤버 나가기 | 팀 나가기 | 팀을 나갔어요 | 없음 |
| 탈퇴 | 회원 탈퇴, 남는 팀마다 | 서비스를 떠났어요 (그때 이름으로) | 없음 |
| 팀 이름 변경 | 이름이 실제로 바뀐 경우만 | 팀 이름을 '우리집'에서 '우리 가족'으로 바꿨어요 | 팀 설정 |

- 내가 한 일은 나에게 안 보인다 (일정과 같은 규칙). 최근 30일, 일정과 합쳐 최신순 50개
- 둘째 줄: 기념일은 "11월 22일, 함께한 날 세기" (올해가 아니면 연도), 그 밖은 없음
- 나간 사람, 탈퇴한 사람은 그때의 표시 이름으로 보인다. 탈퇴한 사람의 다른 기록(기념일 추가 등)은 지금처럼 "탈퇴한 멤버" (Q3)
- 기념일을 지우고 5초 되돌리기를 누르면 아무 일도 없던 것처럼 기록이 남지 않는다 (Q2)
- 새 소식 배지 수에 이 기록들도 더한다
- 강조나 맨 위 고정은 없다. 일반 줄 (Q4)

## 4. 제외

| 제외 | 이유 |
|------|------|
| 멤버 색, 표시 이름 변경 기록 (Q1) | 화면에서 바로 보이고 소음이 크다 |
| 초대 코드 재발급 기록 | 다른 멤버가 알 필요가 적다 |
| 새 푸시 종류 | 기념일 변경, 나가기, 팀 이름은 푸시하지 않는다. 합류 푸시는 지금 그대로 |
| 30일 지난 기록 정리 | 일정 기록과 같이 두지 않는다. 행 수가 작다 |

## 5. 제약

- 새로 모으는 개인정보 없음 (팀 안에서 이미 보이는 정보의 기록). 개인정보 라벨, 스토어 변경 없음
- 앱 네이티브 변경 없음 (웹 배포만)

## 6. 성공 기준

1. 기념일 변경, 합류, 나가기, 팀 이름 변경이 같은 트랜잭션으로 기록된다 (자동 테스트)
2. 옛 웹은 배포 겹침 동안 새 소식이 깨지지 않는다 (`v=2` 없으면 예전 응답, 자동 테스트)
