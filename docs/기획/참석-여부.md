# 일정 참석 여부와 짧은 반응 기획

- 이슈: #190 (로드맵 #205, P2)
- 상태: 이슈 초안의 추천안으로 진행 (주인 확정 전, "정할 것" 은 모두 추천안)
- 작성: 2026-11-13
- 선행: 일정 참여자(#248), 새 소식 확장(#191)

## 1. 목표와 대상

**누가**: 가족 모임, 친구 모임(3~10명)처럼 참여자가 여럿인 팀.

**지금 문제**: 참여자로 "누가 가는 일정인지" 는 정하지만, 그 사람이 실제로 갈 수 있는지는 카톡으로 다시 묻는다. "봤어" 정도의 가벼운 확인도 할 방법이 없다.

## 2. 핵심 흐름

| # | 유저 스토리 | 완료 기준 |
|---|------------|-----------|
| R1 | 참여자로서, 이번 모임에 갈 수 있는지 한 번 눌러 남기고 싶다 | 일정 상세에서 참석, 미정, 불참 중 하나를 누르면 저장되고 바꿀 수 있다 |
| R2 | 일정을 만든 사람으로서, 누가 오는지 한눈에 보고 싶다 | 상세에 "참석 3, 미정 1, 응답 전 2", 누르면 사람별 목록 |
| R3 | 참여자가 아닌 팀원으로서, 봤다는 표시만 남기고 싶다 | 좋아요, 기대돼요, 확인했어요 중 하나. 다시 누르면 취소 |
| R4 | 매주 모임 참여자로서, 이번 주만 빠진다고 하고 싶다 | 반복 일정은 회차마다 따로. 이번 주 불참이 다음 주에 번지지 않는다 |
| R5 | 바쁜 사람으로서, 아직 답하지 않은 일정을 놓치지 않고 싶다 | 다가오는 일정 카드와 목록 화면에 "응답" 글자 |

## 3. 규칙

- 참석 여부는 **그 회차의 참여자만** 남긴다. "모두" 면 지금 팀원 전원. 참여자 없음 일정은 응답 줄이 없다. 참여자가 아닌 사람은 참여자로 넣는 것이 먼저다(Q6)
- 값은 참석, 미정, 불참 + 응답 안 함. 남의 응답은 바꿀 수 없다
- 반응은 팀원 누구나, 사람당 하나, 정해진 낱말 3개(좋아요, 기대돼요, 확인했어요, 이모지 없음, Q5)
- 반복 일정은 회차마다 따로. "이 일정만" 으로 시각을 옮겨도 응답은 그 회차에 남는다. "이후 모두" 로 나누면 그 회차 이후 응답이 따라가고, 날짜나 주기를 바꾸면 맞는 회차가 없어 지워진다
- 일정 시각이 바뀌어도 응답은 지우지 않고 "답한 뒤에 시간이 바뀌었어요" 를 보여 준다(Q2)
- 참여자에서 빠지거나 팀을 나가면 그 사람 응답이 지워진다. 다시 넣어도 돌아오지 않는다
- 지난 일정도 응답을 바꿀 수 있다(사후 기록). "응답" 표시는 끝나지 않은 일정에만
- 개인 달력에는 두 줄 모두 없다

## 4. 알림과 새 소식

- 새 소식: 참석 여부를 정하거나 바꾸면 "○○님이 '저녁 약속'에 참석으로 답했어요". 같은 회차를 2분 안에 여러 번 바꾸면 마지막 한 줄. 반응은 남기지 않는다
- 푸시: 보내지 않는다(Q1). 쓰임을 본 뒤 "등록자에게 불참만" 을 검토
- 일정 알림: 불참으로 답한 회차에는 보내지 않는다. 빈 시간 계산은 그대로(참여자면 바쁨, Q3)

## 5. 제외

댓글, 자유 문장 반응, 이모지, 응답 마감, 응답 독촉 푸시, 불참을 빈 시간에 반영, 참여자가 아닌 사람의 참석 응답
