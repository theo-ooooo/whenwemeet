# 반복 일정 기획

- 이슈: #187
- 상태: 기획 승인 (2026-11-10)
- 작성: 2026-11-10
- 관련: 일정 알림 #188 (반복 일정의 회차마다 알림), ICS 내보내기 #193 (규칙을 RRULE 로 옮긴다)

## 1. 목표와 대상

**누가**: 매주 같은 요일에 만나는 연인, 격주로 모이는 가족, 매달 같은 날 회비를 내거나 정기 모임이 있는 팀.

**어떤 순간에**: "매주 수요일 저녁" 을 지금은 주마다 하나씩 새로 만들어야 한다. 한 번 등록하면 달력에 계속 보이고, 이번 주만 빠지는 날은 그 회차만 바꾸게 한다.

**지금 상태 (develop 4440713)**: 일정은 한 번짜리뿐이다. MVP 기획 4장에서 "예외 처리 복잡도" 로 제외했다.

## 2. 핵심 흐름

| # | 유저 스토리 | 완료 기준 |
|---|------------|-----------|
| R1 | 연인으로서, "매주 수요일 저녁" 을 한 번만 등록하고 싶다 | 일정 작성에서 반복 "매주" 를 고르고 저장하면 이후 모든 수요일 칸에 보인다 |
| R2 | 팀원으로서, 이번 주만 시간이 바뀐 회차를 그 회차만 고치고 싶다 | 회차를 열어 수정 → "이 일정만" → 그 주만 바뀌고 다른 주는 그대로 |
| R3 | 모임이 끝났을 때, 다음 주부터의 반복을 한 번에 멈추고 싶다 | 회차에서 삭제 → "이후 모두" → 그 회차부터 사라지고 지난 회차는 남는다 |

## 3. 규칙

### 3-1 반복 주기 (확정, Q1)

| 주기 | 값 | 회차 날짜 |
|------|----|----------|
| 반복 안 함 | (없음) | 지금과 같다. 기본값 |
| 매주 | `WEEKLY` | 시작일과 같은 요일, 7일 간격 |
| 격주 | `BIWEEKLY` | 시작일과 같은 요일, 14일 간격 |
| 매월 | `MONTHLY` | 시작일과 같은 날짜. 그 날짜가 없는 달은 말일 (31일 → 4월 30일, 2월 28/29일) |
| 매년 | `YEARLY` | 시작일과 같은 월일. 2월 29일은 평년에 2월 28일 (기념일 3-2 와 같은 규칙) |

- 기준은 언제나 **첫 회차의 시작일** 이다. 매월 31일 규칙은 2월에 28일로 가도 3월에는 다시 31일이다
- 시각, 길이, 종일 여부는 모든 회차가 같다. 시각은 KST 벽시계 기준 (한국은 서머타임이 없다)
- 여러 날 일정도 반복할 수 있다. 단 **길이가 주기보다 짧아야** 한다 (매주 반복인데 8일짜리는 저장 거부. 회차끼리 겹치지 않게). 매월과 매년은 28일, 365일 기준

### 3-2 종료 조건 (확정)
- **계속** (기본) 또는 **날짜까지** (그날 시작하는 회차까지 포함)
- 종료 날짜는 첫 회차 시작일 이후만 고를 수 있다
- "N회 반복" 은 두지 않는다 (날짜로 대신할 수 있고, 회차 예외와 섞이면 셈이 헷갈린다)

### 3-3 회차를 만드는 방식
기념일 3-3 처럼 **미리 목록을 만들지 않고 요청한 기간만 계산** 한다. "계속" 이어도 저장 공간이 늘지 않는다.

| 쓰는 곳 | 범위 |
|---------|------|
| 달력 | 보이는 6주 그리드 |
| 다가오는 일정 | 오늘 ~ 30일 (지금 규칙 그대로) |
| 빈 시간 찾기 | 검색 기간. 각 멤버의 모든 팀(개인 팀 포함) 반복 일정 회차가 "바쁨" 에 들어간다 (MVP 빈 시간 규칙 그대로) |
| 일정 알림 #188 | 다음 회차 |

### 3-4 수정과 삭제 (확정, Q2)
반복 일정의 회차를 수정하거나 삭제하면 범위를 묻는다. 반복이 아닌 일정은 지금처럼 묻지 않는다.

| 선택 | 수정 | 삭제 |
|------|------|------|
| 이 일정만 | 그 회차만 바뀐다 (제목, 시각, 메모). 이후 반복 규칙을 바꿔도 이 회차는 바뀐 값 유지 | 그 회차만 사라진다 |
| 이후 모두 | 이 회차부터 새 값으로. 앞 회차는 그대로 남는다 | 이 회차부터 모두 사라진다. 앞 회차는 남는다 |

- 첫 회차에서 "이후 모두" 를 고르면 전체가 바뀐다. "전체" 선택지를 따로 두지 않는 이유
- **반복 주기와 종료 조건은 "이후 모두" 에서만** 바꿀 수 있다. "이 일정만" 시트에는 반복 칸을 숨긴다
- "이후 모두" 로 반복을 "반복 안 함" 으로 바꾸면 이 회차는 한 번짜리 일정이 되고 이후 회차는 사라진다
- 반복이 아닌 일정을 수정해 반복을 켜면 그 일정이 첫 회차가 된다
- "이후 모두" 로 바꿀 때, 그 뒤에 있던 "이 일정만" 예외는 버린다 (새 규칙과 어긋날 수 있다. 확인 문구에 "이후 따로 바꾼 회차도 새 값으로 바뀌어요" 를 쓴다)
- 반복을 모두 지운 뒤에도 지난 회차의 새 소식 기록은 남는다

### 3-5 표시
| 위치 | 동작 |
|------|------|
| 일정 작성/수정 | 시각 아래 "반복" 줄: 반복 안 함 / 매주 / 격주 / 매월 / 매년. 반복을 고르면 "종료" 줄: 계속 / 날짜까지(날짜 선택) |
| 일정 상세 | 시각 아래 한 줄 "매주 수요일" "격주 수요일" "매월 31일" "매년 5월 5일". 종료가 있으면 다음 줄에 "12월 31일까지" |
| 달력 칸, 다가오는 일정 | 다른 일정과 같은 모양. 반복 아이콘은 달지 않는다 (칸이 좁고, 상세에서 보인다) |
| 범위 선택 | 하단 시트 두 줄 "이 일정만" "이후 모두" + 취소. 삭제 시트는 빨간 글자 |

### 3-6 새 소식
- 반복 일정 하나에 대한 동작은 **기록 1건** (회차마다 남기지 않는다)
- 문구: "매주 반복 일정을 추가했어요", "11월 18일 일정만 수정했어요", "11월 18일부터 반복 일정을 수정했어요", "11월 18일부터 반복을 삭제했어요"
- #188 의 팀원 변경 푸시도 이 기록 단위로 1건

| 반복 | 결과 |
|------|------|
| 2026-11-11(수) 19:00~21:00 매주, 계속 | 11-18, 11-25, 12-02 ... 모두 19:00~21:00 |
| 2026-11-11 매주, 11-25 "이 일정만" 20:00 으로 | 11-25 만 20:00, 12-02 는 19:00 |
| 2026-11-11 매주, 12-02 에서 "이후 모두" 삭제 | 11-11, 11-18, 11-25 만 남는다 |
| 2026-11-11 격주 | 11-25, 12-09, 12-23 |
| 2026-01-31 매월 | 2-28, 3-31, 4-30, 5-31 |
| 2024-02-29 매년 | 2025-02-28, 2026-02-28, 2028-02-29 |
| 2026-11-14(토) 종일 2일(토~일) 매주 | 11-21~22, 11-28~29 |

| 2026-11-11 매주, 종료 2026-11-25 | 11-11, 11-18, 11-25 (종료일 포함) |

## 5. MVP 제외

| 제외 | 이유 |
|------|------|
| 매일, 매주 여러 요일, "매월 둘째 주 화요일" | 수요 확인 후. 규칙 저장은 RRULE 부분 집합이라 나중에 넓힐 수 있게 설계 |
| N회 반복 | 3-2 |
| "전체" 수정 선택지 | 첫 회차 "이후 모두" 로 같은 결과 |
| 회차 끌어서 옮기기 | 달력 끌기 자체가 없다 |
| 외부 캘린더 반복 일정 가져오기 | #194 |

## 6. 제약
- 개인정보: 새로 받는 정보 없음. 기존 일정 필드에 규칙만 붙는다
- 운영 비용: 회차를 저장하지 않아 DB 증가 없음. 달력 요청 하나에 반복 일정 계산이 붙는다 (팀당 수십 개 수준이면 무시할 만함, 설계에서 상한 확인)
- 앱: 웹 화면만 바뀐다. 스토어 재심사 없음

## 7. 성공 기준
1. 출시 4주 뒤 새로 만든 일정 중 반복 일정 비율 10% 이상 (EventLog 로 측정)
2. 반복 일정 관련 버그 신고 0건 (3-7 예시 전부 단위 테스트 통과)
3. 달력 월 조회 응답 시간 p95 가 출시 전 대비 +50ms 이내
