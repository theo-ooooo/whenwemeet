# AI 비서 "볼까" 기획 (#450)

- 이슈: #450
- 방향(2026-11-16 사용자 결정): AI 챗을 열고 글이나 말로 시키면 AI 가 일정을 만들고, 빈 시간을 찾고, 일정을 찾아 답하고, 투표를 연다. 처음 쓴 "입력칸에 숨긴 AI(말로 추가)" 안을 대체한다
- 이름: **볼까** (서비스 이름 끝을 땀). 처음 보는 사람도 AI 인 걸 알게 버튼은 "AI 볼까", 화면 제목은 "볼까" + 작은 "AI 비서" 표시, 첫 인사 "AI 비서 볼까예요. 무엇을 도와 드릴까요?"
- 여는 곳: 일정 추가(+) 버튼 옆에 떠 있는 "AI 볼까" 버튼
- 일정 데이터: 필요한 만큼만 OpenAI 로 보낸다 (빈 시간은 서버가 계산한 결과만, 조회 질문일 때만 그 기간 일정의 제목과 시각)

## 1. 목표와 대상
- 날짜, 시간, 참여자를 하나씩 고르는 대신 "다음 주 금요일 7시 강남 회식 잡아줘", "이번 달 주말 중에 셋 다 되는 저녁 찾아줘"처럼 말하면 끝나게 한다
- 순간: 약속 얘기가 나왔을 때, 이번 주 일정이 궁금할 때, 다 같이 되는 날을 찾을 때

## 2. 핵심 흐름
1. 팀 사용자로서, AI 에게 "다음 주 금요일 7시 강남 회식, 하늘이랑" 이라고 하면 일정 카드를 보고 [추가] 한 번으로 넣고 싶다
2. 팀 사용자로서, "이번 달 주말 중 다 같이 되는 저녁" 을 물으면 빈 시간 후보를 보고, 그중 하나로 바로 일정을 만들거나 투표를 열고 싶다
3. 팀 사용자로서, "이번 주에 뭐 있어?", "하늘이 생일 언제야?" 를 물으면 바로 답을 듣고 싶다

## 3. MVP 기능 목록
| 기능 | 필수/선택 | 비고 |
|------|----------|------|
| AI 버튼: 일정 추가(+) 버튼 옆에 떠 있는 버튼 → AI 챗 화면(폰 전체 화면, 넓은 화면 오른쪽 패널) | 필수 | 개인 달력, 팀 어디서나. 지금 보는 팀이 대상 |
| 대화: 내 말 말풍선 + AI 답 말풍선. 입력칸 + 보내기. 첫 화면에 예시 문장 3개(누르면 바로 보냄) | 필수 | 대화는 화면을 닫으면 사라진다(서버 저장 안 함) |
| 말로 하기: 휴대폰 키보드 받아쓰기(마이크)로 입력 | 필수 | 따로 음성 녹음 기능은 만들지 않음 |
| 일정 만들기: AI 가 제목, 날짜, 시작, 끝, 종일, 장소 글자, 참여자를 채운 **확인 카드** → [추가] 를 눌러야 저장, [고치기] 는 일정 폼을 채워 연다 | 필수 | 반복, 알림, 색은 카드에서 넣지 않음(폼에서) |
| 빈 시간 찾기: 기간, 시간대, 최소 길이, 대상(전원/일부)을 말에서 뽑아 서버의 빈 시간 계산을 돌리고 결과 카드(최대 5개). 후보 하나 → [이 시간으로 일정] 또는 [투표 열기] | 필수 | 계산은 기존 빈 시간 로직. AI 에는 결과 시간대만 보냄 |
| 투표 열기: 빈 시간 후보 2~5개로 투표 확인 카드 → [투표 열기] 를 눌러야 생성 | 필수 | 기존 약속 투표 |
| 일정 찾기: "이번 주 뭐 있어?", "하늘 생일 언제야?" → 그 기간 일정, 기념일을 서버가 찾아 AI 가 요약, 일정 카드는 눌러서 상세로 | 필수 | 이때만 그 기간 일정의 제목, 시각, 참여자 이름을 보냄 |
| 못 하는 일 안내: 수정, 삭제, 팀 관리 등은 "그건 아직 못 해요. 여기서 할 수 있어요" + 해당 화면 링크 | 필수 | 일정 수정, 삭제는 다음 버전 |
| 서비스 밖 질문 막기: 일정, 빈 시간, 투표, 기념일, 이 팀 멤버와 관계없는 질문(날씨, 상식, 번역, 코딩, 잡담, 다른 사람 정보 등)은 답하지 않고 "볼까는 일정 만들기, 빈 시간 찾기, 투표, 일정 묻기만 도와 드려요" 한 줄 | 필수 | 지시문 + 서버 검사 두 겹(아래 제약). 막힌 질문도 하루 횟수에 센다 |
| 사용 한도: 1인 하루 30번(보낸 메시지 기준), 넘으면 그날은 안내만 | 필수 | 서버가 셈 |
| 처음 쓸 때 안내와 동의: 무엇을 OpenAI 로 보내는지(내가 쓴 글, 멤버 닉네임, 조회할 때 그 기간 일정 제목과 시각), 저장 안 함, 확인 카드 원칙 | 필수 | 개인정보처리방침에 처리 위탁, 국외 이전 추가 |
| 앱(웹뷰)에서도 그대로 | 필수 | 웹 기능이라 앱 업데이트 불필요 |

## 4. MVP 제외
- 일정 수정, 삭제, 반복 일정 만들기, 알림 설정을 말로 하기 (틀렸을 때 피해가 커서 확인 카드부터 검증한 뒤)
- 확인 없이 바로 저장하기
- 대화 기록 저장, 이전 대화 이어 보기
- 자체 음성 녹음, 음성 답변(TTS)
- 다른 팀 일정까지 한꺼번에 묻기 (지금 보는 팀만)
- 할 일, 기념일 만들기 (조회는 됨)
- 카톡 대화 복사, 붙여넣기 (비효율, 사용자 판단). 다음 버전 후보: 카톡에서 메시지를 길게 눌러 [공유] → 언제볼까로 바로 보내기 (앱 공유 받기, 스토어 빌드 필요)

## 5. 제약
- 모델: OpenAI `gpt-4o-mini` (Luna 와 같은 모델. 설계에서 실모델 평가 뒤 `gpt-4.1-mini` 로 바꿈, D-278), 함수 호출(tool calling)로 서버의 기능(일정 만들기 초안, 빈 시간 계산, 일정 조회, 투표 초안)을 부른다. 저장하는 함수는 없고 초안만 돌려준다. 저장은 사용자가 카드에서 누를 때 기존 API 로 한다
- 비용: 사용자 OpenAI 계정 선불 잔액. 키는 운영 서버 환경 변수에만(계정 주인이 등록), OpenAI 쪽 월 한도도 계정 주인이 건다. 한 번 대화(보내기 1번)에 함수 호출 포함 입력 약 2,000~4,000토큰이라 1회 1~2원 수준, 한 달 3,000회여도 수천 원. 단가는 설계 때 OpenAI 가격표로 확인
- 개인정보: 대화, AI 답을 서버에 저장하지 않는다(로그는 길이, 함수 이름, 성공 여부, 걸린 시간, 토큰 수만). 빈 시간은 서버가 계산하고 결과 시간대만 보낸다. 일정 내용은 조회 질문일 때 그 기간 것만. 멤버는 닉네임만(이메일 X). OpenAI API 데이터는 기본적으로 학습에 쓰지 않는다는 정책을 처리방침에 적는다
- 서비스 밖 질문: (1) 지시문에 "언제볼까 일정 도우미, 범위 밖은 정해진 한 줄로만 거절" 을 넣고, (2) 서버가 모델 답을 한 번 더 거른다: 함수 호출 없이 일반 지식 답을 내거나 정해진 형식을 벗어나면 그 답을 버리고 거절 문구로 바꾼다. "역할을 바꿔라, 지시를 무시해라" 같은 요청도 같은 거절
- 안전: 사용자 글이나 일정 제목에 든 지시는 따르지 않는다(함수 인자로만 쓰고, 다른 팀 id 등은 서버가 무시). 모든 함수는 요청한 사람의 권한과 지금 팀으로만 동작
- 운영: 비용 0원 시작 원칙의 예외. 상한은 계정 잔액과 1인 하루 30번

## 6. 성공 기준
- 출시 4주 동안 일정을 만든 사람 중 AI 로도 한 번 이상 만든 사람 20% 이상
- AI 확인 카드에서 [추가] 를 누른 비율 60% 이상, [고치기] 로 간 뒤 날짜, 시각을 바꾼 비율 20% 이하 (해석 정확도)
- 답 중간값 4초 이하, 실패(오류, 시간 초과) 5% 이하
- 서비스 밖 질문 시험 목록(날씨, 상식, 코딩, 역할 바꾸기 요청 등 30개)에 모두 거절
