## 결함

### Medium

**#56 6자리 초대 코드를 입력해 합류할 화면이 없음** (F1-07, frontend)
- 재현: 팀 설정의 초대 문구는 "링크를 열거나 코드를 입력하면" 이지만, 코드만 받은 사용자가 앱 안에서 코드를 넣을 곳이 없다. `/join/<코드>` 를 주소창에 직접 쳐야 한다
- 기대: 기획 필수 기능 "초대 링크 + 6자리 코드". API `POST /groups/join` 은 정상
- 분류 근거: 링크 공유로 합류할 수 있어 Medium. 화면흐름.md 에도 입력 화면 정의가 없어 설계 확인 필요. 코드 공유를 주 경로로 볼 거라면 High 로 올려야 한다

**#57 모바일 FAB(+) 가 선택한 날짜가 아닌 처음 날짜로 새 일정 폼을 연다** (F2-03, frontend)
- 재현: 모바일에서 `?date=2026-11-21` 로 진입 → 26일 탭 → + 탭 → 폼이 11월 21일로 열림
- 기대: 선택일(26일) 10:00~11:00. PC 상단 "일정 추가" 는 정상
- 스크린샷: `img/qa-bug-fab-stale-date.png`

**#58 빈 시간 찾기 시간대에 24:00 을 고르면 400 오류** (F3-09, frontend)
- 재현: `/g/<id>/free` 종료 select 에서 24:00 → "dayEnd 는 HH:mm 형식이어야 해요"
- 기대: 선택지에 있는 값은 계산되거나, API 가 받지 않는 값은 선택지에 없어야 함
- 스크린샷: `img/qa-bug-free-dayend-2400.png`
