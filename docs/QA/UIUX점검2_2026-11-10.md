# UI/UX 2차 점검 (2026-11-10)

- 이슈: #160. 결함 이슈: #175 (High), #166 ~ #173 (Medium 8건), #174 (Low 14건 묶음)
- 대상: develop `f9f55ea` (v0.4.2 이후)
- 기준: 1차(#131, `UIUX점검_2026-11-10.md`)는 대비, 44px, 넘침 같은 규칙을 봤다. 이번에는 **사람이 보자마자 어색하다고 느끼는 것**을 찾았다. 짝/형제 요소를 나란히 놓고 크기, 글자, 면, 간격을 쟀고, 주장마다 나란히 비교 이미지(`img/ux2-*.png`)를 만들었다

## 판정

High 1건, Medium 8건, Low 14건. 기능이 막히는 곳은 없다. High 는 가장 흔한 폰 폭(360~393)에서 바쁜 날의 주 버튼이 잘리거나 사라지는 문제다. Medium 은 대부분 "같은 줄, 같은 화면의 형제가 서로 다르게 생김"(버튼 셋, 버튼 폭, 이름 편집 방식, + 두 개)과 "색과 위계가 뒤집힘"(먹색 아바타, 이름이 제목을 밀어냄, 기념일 값)이다.

## 문제없음으로 확인한 것

- 로그인, 초대(로그아웃)의 카카오/애플 짝: 48px, 모서리 12, 15/700, 아이콘 20 칸, 간격 8 로 같다 (`SocialLoginButton`, `APPLE_LOGIN_ENABLED=1`). 라이트/다크 정상
- 앱 셸(iOS, Android UA + 브리지 스텁): 로그인은 '로그인 화면을 여는 중이에요' + '로그인 화면 다시 열기' 대기 상태, 초대는 '로그인하고 합류하기' 하나. 웹 소셜 버튼과 애플 버튼은 숨겨진다
- 30자 팀 이름: 상단 바, 팀 전환 시트, 내 정보, 사이드바에서 말줄임 정상. 20자 닉네임: 멤버 목록, 새 소식(줄바꿈), 상세 '...가 등록' 정상. 이름 끝 받침에 따른 '이/가' 조사 정상 (`lib/text.ts`)
- 7색 멤버: 점, 막대, 팔레트 정상. 빠른 추가 저장 → 토스트 '일정을 추가했어요' → 시트 닫힘 정상 (실제 탭 순서로 확인)
- 확인 창과 시트의 어두운 막은 떠 있는 탭과 + 도 덮는다 (`elementFromPoint` 로 확인)
- 폴드/듀오/PC 에서 화면별 본문 폭(빈 시간, 팀 설정 640/720, 기념일, 새 소식, 새 일정 656) 과 제목 왼쪽 끝은 화면끼리 같다

## 재현 메모

- 3160 포트는 다른 작업(#159)의 개발 서버가 쓰고 있어 3162 로 띄웠다: `API_MOCK=1 APPLE_LOGIN_ENABLED=1 next dev -p 3162`
- 엣지 데이터는 목 스토어(`globalThis.__wwmMockStore`)에 넣었다. 목 API 는 등록된 사용자만 받아 7명 팀을 HTTP 로 만들 수 없어서, 개발 서버 프로세스에 `kill -USR1 <pid>` 로 인스펙터를 열고 `Runtime.evaluate` 로 사용자, 멤버십, 일정을 넣었다. 사진은 `/Library/User Pictures` 를 `sips` 로 jpg 변환해 `__wwmMockFiles` 에 넣었다
- `next dev --inspect` 로 띄우면 페이지가 1초에 몇 번씩 새로고침되는 루프가 생겼다 (로그에 `✓ Compiled in 0ms` 반복). 개발 도구 문제라 결함으로 적지 않았다. 인스펙터가 필요하면 기동 뒤 `SIGUSR1` 을 쓴다
