## 고친 것 (QA 중)
- 상세 작은 지도가 높이 0 으로 안 보임(`relative` 와 `absolute` 충돌) → `size-full`
- 라이트에서 길찾기 버튼 면(`--hover`)이 칸 바탕과 같아 버튼으로 안 보임 → `--paper` 면 + 1px `--line`

## 확인 못 한 것
- **실제 카카오 지도 그림**: 도메인이 등록된 JS 키가 로컬에 없어 지도는 SDK 와 같은 모양의 스텁(`window.kakao.maps` 가짜)으로 화면 흐름만 확인했다. 운영 키와 도메인 등록 뒤 실제 지도, 핀, 끌기, 확대를 다시 본다
- **실제 카카오 로컬 검색**: REST 키가 없어 가짜 공급자로만. 카카오 응답 매핑은 단위 테스트(fetch 목)
- 앱(iOS, Android 웹뷰)에서 길찾기가 카카오맵 앱이나 브라우저로 넘어가는지 (셸이 외부 https 를 OS 로 넘기는 기존 동작에 기댄다)
- 목 모드(`API_MOCK=1`)는 단위 테스트(목 핸들러)만
