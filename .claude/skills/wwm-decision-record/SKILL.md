# 결정 기록 (D-번호)

- 파일: `docs/설계/결정기록.md` 표 맨 아래에 한 줄 추가. 번호는 마지막 D-번호 + 1
- 형식: `| D-n | (#이슈) **결정 한 문단** (설계 \`<문서>.md\`) | 이유 |`
- 결정에는 숫자와 이름을 그대로: 컬럼, 기본값, 엔드포인트, px, 색 토큰, 마이그레이션 이름
- 이유에는 사용자 피드백이나 사고 번호처럼 왜 이 길을 골랐는지
- 앞선 결정을 바꾸면 새 줄에 "(D-xxx 보완)" 이나 "(D-xxx 대체)" 를 쓰고 옛 줄은 지우지 않는다
- 자세한 내용은 `docs/설계/<주제>.md` 에, API 는 `docs/설계/api.md` 에 함께 반영
- 묻지 않고 스스로 정한 결정도 여기에 남긴다 (사용자에게 묻는 건 돈, 스토어 제출, 약관 정도)
